  ### Régimen de aprobación de la materia

  \
  Para aprobar la materia se deben aprobar las prácticas, el taller y el examen final. \
   Para aprobar las prácticas se deben aprobar dos exámenes parciales. Para los alumnos que desaprueben alguno o ambos de estos exámenes, habrá dos fechas de recuperación al finalizar el cuatrimestre.  \
   Para aprobar el taller se deben aprobar dos trabajos prácticos. Más información puede encontrarse en la página del taller. \
   La aprobación de la práctica y el taller es independiente, esto quiere decir que pueden aprobarse por separado en cuatrimestres distintos. \
   Una vez aprobados la práctica y el taller, puede rendirse el examen final.\
